# Pre-commit Hook ctx sync Analysis — 2026-05-22

## Bug

`scripts/hooks/pre-commit` line 35 triggers `trifecta ctx sync` on any `_ctx/*` change, including runtime-generated artifacts that regenerate on every sync, creating an infinite dirty loop.

## Current Regex

```bash
CTX_FILES="^(skill\.md|prime_.*\.md|agent\.md|session_.*\.md|README\.md|_ctx/.*)$"
```

**Problem**: `_ctx/.*` matches **everything** under `_ctx/`, including:

- `_ctx/telemetry/events.jsonl` — runtime telemetry, regenerated on every sync
- `_ctx/telemetry/last_run.json` — runtime state
- `_ctx/generated/repo_map.md` — regenerated by `trifecta ctx sync`
- `_ctx/generated/symbols_stub.md` — regenerated by `trifecta ctx sync`

## Impact

When committing any file under `_ctx/` (e.g., `_ctx/session_trifecta_dope.md`), the hook:

1. Detects "context files changed"
2. Runs `trifecta ctx sync --segment .`
3. `ctx sync` regenerates `repo_map.md`, `symbols_stub.md`, `events.jsonl`, `last_run.json`
4. These regenerated files become dirty
5. Next commit triggers the same cycle → **infinite dirty loop**

This caused 2 extra commits in publish-main-backlog (`38057871` → `68cf5090` → `b6a0b656`) that were pure ctx sync regen.

## Proposed Fix

### New Regex

```bash
CTX_FILES="^(skill\.md|prime_.*\.md|agents?\.md|session_.*\.md|README\.md|_ctx/agent_.*\.md|_ctx/session_.*\.md|_ctx/index/.*)$"
```

### Diff

```diff
-CTX_FILES="^(skill\.md|prime_.*\.md|agent\.md|session_.*\.md|README\.md|_ctx/.*)$"
+CTX_FILES="^(skill\.md|prime_.*\.md|agents?\.md|session_.*\.md|README\.md|_ctx/agent_.*\.md|_ctx/session_.*\.md|_ctx/index/.*)$"
```
